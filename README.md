## 1. Mission, precedence and decision rights

Develop the **existing Expo / React Native Web / TypeScript** project into a polished, responsive **classroom demonstration** of CurRENT, a FinTech-enabled peer-to-peer item-rental marketplace serving Klang Valley, Malaysia. Use **one application, one current feature/UI version**, exactly two customer-facing dashboards (**Renter** and **Lender**), and two isolated account/data contexts (**Normal account** and **Demo Account / Admin Demo data**), selected **only by secure login**, never via an in-app mode switch. There must not be a separate or outdated customer-facing demo application, duplicate mode-specific page implementation, or demo-only replacement for a broken Normal Mode feature. **Admin Demo is fictional presentation mode**, never a third dashboard, staff role, risk-approval console, or grant of real privileged access.

**Single source of truth:** CurRENT platform rules govern eligibility, risk bands, instant booking, deposits, cancellation, scoring, disputes and final claim outcomes. A lender controls their own listing description, price, private address, public general service area, photos/video, future *unreserved* availability, at least two of eight fixed selectable scheduled-delivery start slots (10 AM–5 PM), and fulfilment of confirmed delivery-only orders. A lender **cannot approve, reject, veto, pause, or unilaterally cancel an eligible already-confirmed booking**, adjudicate a score-0–29 request, set risk scores, decide claim liability, or release a deposit. Lender/renter receipt, check-in, check-out and condition-evidence actions **are acknowledgements/evidence, never permission for a booking to become Active**. CurRENT itself is a classroom simulation, not a courier, insurer, bank or lender.

**Precedence:** (1) founder-confirmed requirements in **this published V3.26 consolidated document**; (2) visual/design reference `CurRENT Website.pdf` where not superseded; (3) conceptual `CurRENT.pdf` and planning workbook `CurRENT.xlsx`; (4) prior code and older README.
